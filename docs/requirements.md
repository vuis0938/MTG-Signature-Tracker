# 项目需求文档 — MTG 签绘管家

## 项目概述

MTG 签绘管家 (MTG Artist Signature Tracker) 是一个供万智牌（MTG）玩家在"线下大型展会前"使用的准备工具。

## 使用场景

- **主要场景**：活动前在家用 PC 准备，手机端查看清单
- **不需要**考虑展会现场的操作

## 核心功能

### 1. 套牌导入与画家清单生成

- 从 Moxfield 导入套牌（CSV 格式）
- 通过 Scryfall API 获取每张卡的精准画家信息
- 生成完整的套牌-画家清单
- 按画家分组展示，每张卡附带图片

### 2. 活动画家名单匹配

- 支持粘贴不同格式的活动画家出席列表（含噪声文本）
- 通过 LLM API 智能清洗，提取纯画家名单
- 与核心列表交叉比对，查找重复画家
- 显示本次活动需要送签的卡牌

### 3. 签名状态管理

- 每张卡牌有"未签"和"已签"两种状态
- 已签卡牌不再参与后续比对
- 需支持签名日期和活动名称的记录

### 4. 多列表管理

- 支持录入多套核心牌表
- 活动匹配时支持多选套牌批量查询
- 跨套牌合并显示匹配结果

### 5. 跨设备使用

- PC 端准备（数据导入、匹配）
- 手机端查看（匹配结果、卡牌清单）
- 数据云端同步

## 页面规划

| 页面 | 路由 | 功能 |
|------|------|------|
| 套牌管理 | `/decks` | 导入/查看/管理套牌，按画家分组展示 |
| 活动匹配 | `/match` | 粘贴活动名单，AI 解析，交叉比对 |
| 设置 | `/settings` | 数据导入导出，API Key 配置，关于 |
| 登录 | `/login` | SECRET_KEY 鉴权 |
