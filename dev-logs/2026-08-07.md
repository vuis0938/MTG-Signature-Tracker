## 关键实现说明

### 状态同步与去重

- 所有卡牌写操作（切换状态、重试、添加卡牌、切换版本、删除）现在同时更新本地 `useState` 与 SWR 缓存（通过 `mutateCards`）。
- 新增 `pendingStatusIds` 集合，避免同一卡牌/卡牌组在请求返回前被重复触发。
- 心动状态统计修复：`delta[3] = { u: 1, p: 0, h: 1 }`，即心动同时计入「待签」与「心动」计数。

### 安全加固

- `src/lib/auth.ts` 中的 `getTokenSecret()` 不再提供任何环境默认值；未设置或长度不足 32 位时直接抛错。
- 登录接口遇到无冒号的明文密码存储时，返回 401 并提示使用「忘记密码」重设。
- 管理员布局改为校验 `auth_token` 签名，而非信任可伪造的 `user_name` cookie。

### SEO / 域名

- Middleware 中对 `mtgkit.top` 返回 308 永久重定向到 `www.mtgkit.top`。
- Sitemap 仅保留 `/`、`/privacy`、`/terms`。
- robots.txt 屏蔽 `/admin`、`/api`、`/decks`、`/match`、`/events`、`/settings`、`/login`。

## 关键实现说明

### 安全加固

- **防用户枚举**：忘记密码接口无论用户是否存在，均返回相同的成功响应与确定性虚假安全问题。
- **PBKDF2 哈希**：安全问题答案与密码统一使用 `600000` 次迭代的 PBKDF2，格式为 `iterations:salt:hash`；兼容旧 `salt:hash` 格式并在验证成功后自动升级。
- **Token 撤销**：`users` 表新增 `token_version` 字段；登录时写入 token payload，改密/登出时递增版本，使旧 token 全局失效。
- **持久化限流**：新增 `rate_limits` 表与 `src/lib/rate-limit.ts` 的 Supabase 实现，失败时自动回退到内存，避免 Serverless 实例间绕过。
- **CSV 安全导出**：`escapeCsvField` 对公式注入前缀加单引号，并按 RFC 4180 转义逗号、引号与换行。

### SEO / 性能

- 首页、隐私政策、服务条款补充 JSON-LD 结构化数据；根 layout 设置 `metadataBase` 与 canonical。
- `CardImage` 支持 `priority` 属性，`decks-client` 对前 6 张首屏卡牌开启优先加载。
- 接入 Vercel Analytics 与 Speed Insights，自动收集页面访问与 Core Web Vitals。

### 测试

- 新增 4 个核心 API 路由测试文件，覆盖登录、注册、改密、忘记密码、登出。
- 新增 `decks-client.test.tsx`，覆盖展开/收起、状态切换乐观更新与回滚、批量修改确认、导入/添加/删除套牌等 10 个用例。
